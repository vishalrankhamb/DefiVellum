# DefiVellum

Highly scalable, distributed data processing architecture utilizing cloud-agnostic, containerized microservices as a robust computation platform engine.

With DefiVellum, you get a lightweight tool that stays out of your way.

**What you get**

- Highly scalable, distributed data processing
- architecture utilizing cloud-agnostic, containerized microservices
- as a robust computation platform

## Key Features

- Highly scalable, distributed data processing
- architecture utilizing cloud-agnostic, containerized microservices
- as a robust computation platform

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiVellum.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DefiVellum is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
